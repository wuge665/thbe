# DevTools - 开发者工具站

免费、开源、易用的在线工具集合网站。

## 功能列表

- JSON格式化 - 美化/压缩JSON数据
- 时间戳转换 - Unix时间戳互转
- Base64编码 - 字符串Base64加密/解密
- URL编码 - URL特殊字符转义
- 密码生成器 - 随机安全密码生成
- 颜色转换 - HEX/RGB/HSL互转
- 字数统计 - 字符/词/行数统计
- Hash加密 - SHA-256/MD5加密
- 二维码生成 - 在线生成二维码

## 开发

```bash
npm install
npm run dev
```

## 构建

```bash
npm run build
```

## 部署

### Vercel (推荐)

1. 安装 Vercel CLI: `npm i -g vercel`
2. 运行 `vercel` 部署

或直接将 `dist` 文件夹部署到任意静态托管服务。
